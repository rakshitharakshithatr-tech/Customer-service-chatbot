# Customer Service Chatbot Using Python

## Project Description

This project is a simple customer service chatbot developed using Python.
It provides automated responses to common customer queries.

## Technologies Used

- Python
- Google Colab
- Basic Natural Language Processing concepts

## Features

- Greeting response
- Working hours information
- Contact information
- Order support
- Refund information
- Thank-you response
- Exit command

## How to Run

Run the Python program and enter a customer query when prompted.

## Example

You: hello

Bot: Hello! Welcome to our customer service. How can I help you?

You: hours

Bot: Our working hours are 9 AM to 6 PM.

## Conclusion

The chatbot demonstrates how Python can be used to provide automated
responses to common customer service queries.
